# 电子靶时钟校验服务

校验射击电子靶时钟与数据顺序，定位对正式成绩的影响。

## 业务事实

- 女子十米气步枪资格赛产生新的亚洲纪录成绩
- 资格赛成绩决定后续晋级
- 纪录发布需要依赖正式竞赛规则与设备数据

## 协作角色

- 运动员
- 电子靶系统
- 裁判与技术官员
- 纪录认证人员

## 服务能力

针对资格赛多靶位逐发数据上传，提供赛前、赛中、赛后全流程时钟校验：

- **登记**：靶机固件、校准源、同步偏差采样、网络中断、人工复位一律登记留档；
  每个成绩事件成对保留设备时间与接收时间，原始命中登记后不可改写。
- **巡检计划**（`src/inspection.py`）：赛前放行闸门（固件/校准源/初始偏差/非隔离），
  赛中采样间隔与隔离状态核查，赛后末次采样时效与隔离处置完备性核查。
- **实时漂移告警**（`src/drift.py`）：逐次同步采样计算偏差与漂移率，
  分级 WARN / ISOLATE；越隔离阈值自动隔离靶位。
  恢复使用必须由技术官员确认登记，系统不自动恢复。
- **离线重传排序**（`src/reorder.py`）：中断恢复后的补传流按发次序号建立规范顺序，
  识别重复、内容矛盾、乱序、超时补传与序号缺口；只标注，不改写原始事件。
- **影响范围报告**（`src/report.py`）：对每一发给出时间基准判定
  （VALID 有效 / REVIEW 须复核 / HOLD 暂缓），
  裁判据此知道哪些发次需要复核，技术代表据此证明正式成绩采用了有效时间基准。

## 目录说明

- `contracts/domain.schema.json` 定义共享资料的字段与基本约束。
- `fixtures/context.json` 提供不含真实个人信息的公开样例。
- `fixtures/rules.json` 规则阈值样例（偏差/漂移率告警与隔离、采样间隔、重传宽限等）。
- `fixtures/scenario.json` 三靶位资格赛场景：健康靶位、时钟漂移隔离靶位、网络中断重传靶位。
- `src/` 领域模型（`models.py`）、规则（`rules.py`）、漂移监测（`drift.py`）、
  巡检（`inspection.py`）、重传排序（`reorder.py`）、影响报告（`report.py`）、
  场景读取（`scenario.py`）与共享资料读取（`records.py`）。
- `demo.py` 赛前-赛中-赛后全流程演示。

## 本地检查

```bash
python -m unittest discover -s tests   # 单元测试
python demo.py                         # 全流程演示
```

运行项目自带测试可确认样例能够读取，领域标识、版本、参与者和记录结构完整。
样例中不包含账号、密钥或连接凭据。

## 设计约束

- 偏差越界自动隔离，但恢复使用必须由技术官员确认（`DriftMonitor.reinstate`
  强制要求官员标识），系统不得自行恢复。
- 所有处置只追加标注与记录，不改写原始命中；矛盾上传双方均留档，交裁判复核。
- 人工复位前后偏差不可比：复位后漂移基线重立，偏差估计不得跨越复位点插值。
